## 七、常见问答(FAQ)

- **Q：需求二的分布式还没做,算「完成」吗?**
    
    本地多维度黑名单(昵称/IP/关键词)已全部实现并测试通过,单机功能完整可用。「分布式」指多实例间实时共享同一份名单,属更高阶能力,经决策暂缓。所以**需求二的功能目标已达成**,分布式作为后续增强项。
    
- **Q：SIGHUP 和 HTTP 重载接口有什么区别,该用哪个?**
    
    两者最终都调用同一个 `Reload()`。**SIGHUP** 适合本机运维脚本、无网络/无鉴权场景(`kill -HUP <pid>`);**HTTP 接口** 适合远程触发且带 Bearer Token 鉴权。任选其一,效果一致。
    
- **Q：热加载时正被高并发访问,会读到一半的脏数据吗?**
    
    不会。`Reload()` 用 `shared_mutex` 写锁**原子替换**整份名单,校验读路径持共享锁;重载期间读不阻塞、也不会脏读。已通过「边重载边压测」的并发测试。
    
- **Q：拉黑一条匿名留言,会把所有匿名用户都封了吗?**
    
    不会。有「匿名极客」护栏——擦除匿名留言时只拉黑它的 **IP**,不会把「匿名极客」这个昵称加进黑名单,其他匿名用户照常发言。
    
- **Q：跑测试会不会污染生产数据?**
    
    非 `--safe` 模式会在 DB 留下几条测试留言、并临时改 `blacklist.txt`(测完自动还原)。想零侵入就用 `--safe` 只读模式;遗留留言可用一条 SQL 手动清理(见测试手册末尾)。
